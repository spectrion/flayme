# What is Flayme?

An experimental local browser-based operating system and development environment with Linux-style virtualization, advanced customization, and an open repo ecosystem.

Flayme is visually inspired by traditional Linux desktop environments rather than any single operating system. It focuses on flexibility, power-user workflows, and making the browser feel like a real desktop.

---

## Warning

Flayme is experimental software and under active development.

Features may change, break, or be redesigned at any time.

Flayme aims to work across modern browsers and is not built around any specific browser engine.

Browser support may vary depending on available web standards, storage limits, performance, and virtualization features.

---

## Overview

Flayme uses modern web technologies to create a local desktop-style environment directly in the browser.

It is designed to support:

- A customizable desktop workspace
- Virtual filesystems
- Linux-style workflows
- Terminal environments
- Modular applications
- Repository-based app installs
- Local-first usage
- Offline-capable features where supported

Flayme can also support external repositories, including compatibility with AnuraOS marketplace repositories and user-created custom repositories.

---

## Philosophy

Flayme is not trying to replace native operating systems.

It is an experiment showing how far the modern web can go while still being practical, hackable, and fun to use.

It is built for users who enjoy customizing systems, testing ideas, and pushing browser technology further.

---

## Current Focus

Flayme is currently focused on core systems such as:

- Desktop interface
- Window management
- File storage systems
- Theme engine
- Repo management
- Linux virtualization
- Performance improvements
- App runtime environment

---

## Customization

Customization is one of Flayme's main goals.

Users will be able to modify:

- Themes
- Wallpapers
- Panels
- Widgets
- Layouts
- Icons
- Startup sessions
- Repositories
- User workflows

---

## Repositories

Flayme supports an open repository model.

This allows:

- Installing apps from supported repositories
- Community-maintained packages
- Custom user repositories
- Third-party marketplaces
- Cross-compatibility with supported ecosystems

---

## Development

Flayme is under active development and not considered stable.

More developer documentation, build instructions, and contribution guides will be added as the project matures.

## Vision

Flayme aims to become a browser OS for people who want freedom, customization, and Linux-style workflows without leaving the web.
